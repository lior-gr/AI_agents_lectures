# Task Planning Skill (Reasoning-Only Guidance)

<!-- This file is prompt guidance, not executable code and not a tool. -->

## When To Use
Use this skill when the user asks to plan, organize, prioritize, or summarize task execution.

## Reasoning Sequence
1. Inspect current tasks before proposing an order.
2. Identify deadlines or urgency signals from existing task text.
3. Prioritize by deadline first, urgency second, effort third.
4. Explain ordering briefly and clearly.

## Constraints
- Never invent tasks that do not exist in the current task list.
- If task data is missing, ask for clarification instead of hallucinating.
- Keep recommendations actionable and tied to real task IDs when possible.

## Output Discipline
- Use concise sections with explicit priorities.
- Separate immediate tasks from later tasks.
- State uncertainties explicitly.
