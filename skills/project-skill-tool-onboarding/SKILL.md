# Project Skill/Tool Onboarding

Read and follow:
- `skills/project-skill-tool-onboarding/project-skill-tool-onboarding.md`

Use bootstrap helper when registries are missing:
- `tools/registry_bootstrapper/run.ps1`

## Minimum completion criteria

- `SKILLS.md` exists and includes the new/updated skill entries.
- `TOOLS.md` exists and includes the new/updated tool entries with argument schema.
- New skills include a dedicated markdown details file.
- New tools expose LLM-usable arguments and schema documentation.
