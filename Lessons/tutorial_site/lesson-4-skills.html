Lesson 4 - Add Skills for reasoning discipline

Skills improve how the model thinks, not how code executes. This lesson is about clean separation between reasoning and runtime control flow.

L4 Concept before coding

Skills live in prompt space only.

Agent loop -> prompt construction (includes skill text) -> model response -> tool call decision

Skill is NOT:

  • Not a loop.
  • Not a subprocess runner.
  • Not a storage layer.
  • Not a tool implementation.

Simple example

A planning skill may say "first inspect existing tasks, then plan realistically." It does not execute the inspection itself.

L4 Create a first skill file

Write clear, reusable reasoning rules.

Prompt to paste into Codex 
Create a new folder called skills.
Inside it create task_planning_skill.md.
The file should:
- Define when this skill should be used
- Provide structured reasoning rules for task planning
- Define constraints (no hallucinated tasks)
- Explain how tasks should be prioritized
- Not include execution logic
- Include comments explaining why this is not a tool
This file is pure text.
No Python.
Student task after generation
  • Check that the skill text is actionable but tool-agnostic.
  • Check constraints are explicit and practical.
  • Check the file does not contain implementation logic.

L4 Inject skill into prompt construction

Reasoning changes only. Execution plumbing stays untouched.

Prompt to paste into Codex 
Modify agent.py so that before sending messages to OpenAI,
it loads task_planning_skill.md and injects it into the system prompt.
The skill must:
- Not modify loop logic
- Not modify tool logic
- Only affect prompt construction
Add detailed comments explaining separation.
Student task after generation
  • Diff should show prompt-construction changes only.
  • Loop, tool call path, and MCP components should be unchanged.
  • Run planning goal and compare response quality with/without skill.

Checkpoint

  1. Does a skill execute tools?
    No. Skills influence reasoning, not execution.
  2. Should loop control change in this lesson?
    No. Only prompt construction should change.
