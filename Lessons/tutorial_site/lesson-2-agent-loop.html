Lesson 2 - Introduce a real minimal agent loop

We now add loop-driven behavior, but we keep strict limits. The goal is controlled autonomy, not open-ended complexity.

L2 Concept before coding

What changes and what stays the same.

Before: User -> CLI -> storage.py -> tasks_db.json After: User -> agent.py -> tools.py -> storage.py -> tasks_db.json

Guardrails to keep from day one

  • max_steps hard limit.
  • Tool whitelist only.
  • Low temperature for stable behavior.
  • Token cap per request.

Simple loop example

Goal: "Add buy milk and then show tasks."
Expected sequence: call add_task, then list_tasks, then stop.

L2 Create agent skeleton

Start with loop and stop conditions first.

Prompt to paste into Codex 
Create a new file agent.py.
Implement a minimal agent loop that:
- Accepts a user goal string
- Calls OpenAI chat completion API
- Supports tool calling
- Has max_steps=5
- Logs each step
- Does not exceed 800 tokens per call
Includes detailed comments explaining:
- Where the loop is
- Where tool calls are processed
- Where stopping conditions are enforced
Do not implement tools yet.
Just stub them.
Student task after generation
  • Find loop block and verify step counter increments safely.
  • Verify stop conditions are explicit and deterministic.
  • Confirm API key uses environment variable.
  • Confirm temperature and token caps are intentionally set.

L2 Add tools and wire CLI goal mode

Agent does not edit JSON directly. It only calls tools.

Prompt to paste into Codex 
Create tools.py.
Define tool schemas for:
- add_task(text: str)
- list_tasks()
- complete_task(task_id: int)
These must call existing storage.py functions.
Do not put business logic inside the agent.
Add detailed comments explaining separation of concerns.

Modify main.py:
Add a new command:
python main.py --goal "Plan my tasks for today"
This should call:
agent.run_agent(goal)
Keep old deterministic commands working.
Student task after generation
  • Run old deterministic CLI commands and confirm no regressions.
  • Run one goal and inspect tool sequence in logs.
  • Confirm storage remains clean and unchanged in role.

Checkpoint

  1. Who owns the loop now?
    The agent in agent.py.
  2. Does storage know an agent exists?
    No. Storage remains a persistence module only.
