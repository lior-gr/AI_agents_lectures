Lesson 5 - Add UI without breaking architecture

We now add a GUI layer. The key rule: UI is a boundary, not a logic center. If backend layers change for UI, architecture leaked.

L5 Concept before coding

UI collects input and renders output. Nothing more.

GUI (ui.py) -> main.py shared backend -> agent -> MCP -> storage

UI must not do these

  • No direct OpenAI calls.
  • No tool execution logic.
  • No direct JSON writes.

Simple example

A submit click should call a shared backend function, not re-implement the agent loop inside UI code.

L5 Create a minimal UI file (Qt6)

Use a professional UI framework while keeping boundaries clean.

Qt6 background (short)

  • Qt6 is a mature cross-platform desktop UI framework.
  • PySide6 is the official Python binding for Qt6.
  • It uses an event-driven model (signals/slots), which fits app-style interfaces well.
  • It is heavier than Tkinter, but scales better for richer UIs.

Checkpoint

  1. Should GUI know OpenAI details?
    No. GUI should stay an interaction layer only.

    Yes, if backend boundaries are clean.
