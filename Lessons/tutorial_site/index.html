Welcome to: Agents, Skills, MCP server & Tools.

This version is intentionally gentle. Each lesson first explains the concept in plain language, then gives you one concrete Codex prompt, then a short student checklist, then a small checkpoint.

Flow How to use each lesson page

No rushing. Read, run, review, reflect.

Learning loop (repeat this for every lesson)

  • Read the concept section and the simple example first.
  • Copy the prompt block and send it to Codex.
  • Do the student review checklist after code is generated.
  • Answer the checkpoint questions, then reveal the answers.

Why this structure works

It keeps coding and learning synchronized. You do not just generate code; you also understand why each architecture decision exists.
