Phase 1

Lesson 1: Building a Baseline System

Before building an agent, we must build a deterministic system that does not require one.

🎯 Goal & Mental Model

If you don’t understand a deterministic baseline, you will not understand what an agent actually adds later.

The Concept: Pure Command → Effect

We are building a system with No Decisions, No Loops, and No Planning.

Example: User types "Add milk" → System writes to file. Done.

🏗️ 1.2 Environment Setup (Windows First)

Open VS Code in an empty folder. We will use Codex to scaffold the project structure.

PROMPT: SCAFFOLD PROJECT 
Create a minimal cross-platform Python CLI project for a task manager.
Requirements:
- Must work on Windows first
- Use argparse
- Store tasks in tasks.json
- Create virtual environment instructions
- Add comments explaining each file
Do NOT implement advanced features yet.

🔍 Inspection Checklist

  • Did Codex separate CLI from storage?
  • Did it include Windows PowerShell setup?
  • Did it avoid premature "AI" features?

🧱 1.4 Architecture & Engineering Rules

We are building a clean boundary system. Separation now avoids confusion later.

  • Storage: Touches JSON directly.
  • Tools: Call storage.
  • Agent: Calls tools.

Rule: Agent logic must NOT go inside storage. Skills must NOT mutate JSON directly.

🎮 1.6 Controlled Prompting Technique

Do NOT ask Codex to "Build a complete task manager." Instead, force iterative growth.

STEP 1: ADD COMMAND
Implement only the --add command. Include detailed comments. Do not implement listing yet.
STEP 2: LIST COMMAND
Now implement --list. Explain how indexing works.

🎯 Lesson 1 Checkpoint

Answer these before moving to Lesson 2:

  2. Where would an agent sit if added? (Above the CLI/Storage layer).
  3. Should storage ever call OpenAI? (No).
  4. Is Codex part of the runtime? (No, it is a dev assistant).
